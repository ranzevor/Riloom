# 产品需求

面向产品负责人、设计者和实现者，定义首版必需能力、触发条件、可观察结果及异常处理。需求范围来自[产品定位与使用场景](overview.md)，实施顺序见[路线图](../project/roadmap.md)。

需求编号跨文档保持稳定。模块、阶段和验收关联由[需求关联数据](requirements.json)维护，数据字段包含需求编号、标题、阶段、设计正文、计划模块和验收场景。children 保存子需求，parentId 指向父需求。父项的汇总验收由各子项共同构成。测试输入与预期集中在[测试与验收方案](../testing/strategy.md)。

<a id="req-01"></a>

## REQ-01 工程创建与分层导入

制作者通过工程创建和分层素材导入建立可编辑模型。工程创建在 M1 提供初始工程与工作区登记，分层导入在 M2 接入 PSD、PNG 素材。两个子项分别由对应场景验收。

<a id="req-01-1"></a>

### REQ-01.1 工程创建与登记

制作者在工作区指定目标目录和画布参数后，应用服务建立具有稳定身份和有效初始修订的空工程，并完成工作区登记与请求回执。

新工程的素材与绘画集合为空，保存后重开保留工程身份和初态。同一请求重投取得原回执与同一工程。目录发布与登记按持久意图协调。

**异常与恢复**

无效画布和占用目录在创建前拒绝。中断后，已完整发布并通过校验的工程补齐登记与回执，不完整创建按操作归属清理并返回失败。

[T01.1 新建空工程](../testing/strategy.md#t01-1)。

<a id="req-01-2"></a>

### REQ-01.2 分层素材导入与重开

制作者导入 PSD、PNG 时，导入适配器与应用服务保留源素材、图层、分组、画框、遮罩、颜色和透明度信息，并将其登记到选定工程。

保存后重新打开，原始素材与解码像素完整，工作副本符合已选颜色转换，分组透明度与嵌套遮罩符合[合成契约](../reference/project-format.md#compositing-and-masks)。逐特性导入结果能定位到对应素材和图层。

**异常与恢复**

损坏像素、资源超限及不能表达的混合效果给出具体对象和处理原因。超色域转换按[颜色契约](../reference/project-format.md#color-management)由制作者选择处理，合法空分组进入工程。

[T01 分层导入与重开](../testing/strategy.md#t01)。

<a id="req-02"></a>

## REQ-02 保护选区、绘画与衣口分层

制作者选择绘画、保护选区或衣口范围后，工位基于固定工程修订生成可比较、可撤销的制作候选。

补画默认按[全画框 PNG 外部编辑往返](../reference/authoring-and-evaluation.md#paint-roundtrip)执行，图像提供方为显式可选路径。回导按源纹素选区组装最终像素，建立派生素材并仅替换所选绘画引用。

保护区域的可见 RGBA、描边和低 Alpha 细节完整保留。衣口结果形成后沿、实际身体、前沿的层序，同时保持几何、UV、局部关键形、父控制、分组、遮罩和动作关系，后续工位读取实际分层素材。

**异常与恢复**

输入冲突或采样不完整时提供对象级诊断，应用操作集合为空。返修沿原姿态和相关控制轨道复验。

[T02 验收场景](../testing/strategy.md#t02)。

<a id="req-03"></a>

## REQ-03 网格、UV 与局部关键形

制作者创建或修改网格时，系统将顶点、UV、三角索引、素材关系和局部关键形映射作为一个完整编辑处理。

顶点与 UV 一一对应，三角索引有效，重布网按[源三角重心映射](../reference/authoring-and-evaluation.md#remesh-mapping)同步全部关键形。默认精确保留同时检查源面覆盖及祖先控制分片，显式采样方式保存范围、容差和完整误差结果。合法镜像 UV 及接缝按来源保留。

**异常与恢复**

缺少 UV、越界索引或精确保留证明失败时，保留输入及具体冲突，应用操作为空。选择明确的采样范围与容差后重新生成候选，完整检查通过后提交。

[T03 验收场景](../testing/strategy.md#t03)。

<a id="req-04"></a>

## REQ-04 父控制与多参数关键形

制作者为任意模型对象设置父控制、局部坐标或多个参数轴时，系统按显式对象关系求值层级与关键形。

非人形、多附肢、非对称结构和共享参数均可表达。父子变换使用[局部绑定、Rotate 与分片 Warp](../reference/authoring-and-evaluation.md#deformation-algorithms)，规则多轴采用多线性插值，稀疏多轴采用显式单纯形重心插值。域外拒绝或显式回退按工程保存的算法版本执行。

**异常与恢复**

层级环、悬空引用和未定义的必需组合给出具体关联对象。修正关系或选择明确的回退策略后重新准备。

[T04 验收场景](../testing/strategy.md#t04)。

<a id="req-05"></a>

## REQ-05 通用状态组、表情、衣装与嘴型

制作者配置或切换表情、衣装、配件和嘴型时，系统按通用状态组的默认选项、互斥关系和覆盖期合成表现。

嘴角形状、开口量和嘴型选择分别控制。各嘴型具有开合行为，快捷键、显示名称与目标动作保持同一映射，追踪输入通过显式映射连接模型参数。

**异常与恢复**

冲突的状态组合或通道配置给出具体原因。切换与退出按当前选中状态恢复各通道。

[T05 验收场景](../testing/strategy.md#t05)。

<a id="req-06"></a>

## REQ-06 动作曲线、追踪混合与随机重放

制作者编辑或播放动作、待机片段和追踪输入时，系统保存曲线形状、插值、循环边界、事件及通道混合规则。

Bezier 手柄和循环接缝可编辑。随机待机由版本化算法、种子、片段权重和冷却规则调度，同一输入与种子可重放，单次动作退出后恢复持续输入。

**异常与恢复**

同优先级 replace 冲突按明确仲裁规则处理，缺少规则时要求修正对应通道。

[T06 验收场景](../testing/strategy.md#t06)。

<a id="req-07"></a>

## REQ-07 物理时步、暖机与轨迹

制作者预览、跳转或离线求值物理系统时，系统使用明确的固定时步、子步、预热、初态与外力轨迹。

内建[有根粒子链](../reference/authoring-and-evaluation.md#particle-chain)固定预测、长度投影、预热计数、默认值与输出单位。跳转从完整检查点重放，连续播放与离线完整采样在规定容差内对应。物理输出按通道拥有权参与模型求值，显示插值沿同一状态轨迹执行。

**异常与恢复**

非有限值与同帧隐式反馈环被定位到具体输入。显式上一时步反馈可用，实时落后时反馈当前播放状态。

[T07 验收场景](../testing/strategy.md#t07)。

<a id="req-08"></a>

## REQ-08 共享求值、渲染与资源生命周期

制作者在 Studio 与离线播放器加载同一工程时，两者使用共享的求值语义和渲染规则。

同一输入得到对应的顶点、UV、工作色域、隔离分组合成、遮罩覆盖率和稳定层序。M2/M3 实现共享模块及资源管理，M4 完成离线播放器对照验收。删除对象、切换工程及图形上下文恢复均释放或重建所属 GPU 资源。

**异常与恢复**

加载失败、图形上下文丢失或显示资源不足时，提供重载、显示分辨率调整及离线检查入口。

[T08 验收场景](../testing/strategy.md#t08)。

<a id="req-09"></a>

## REQ-09 原子编辑、冲突与请求重放

任何入口提交工程编辑时，应用服务核对工程修订、状态前提、请求身份及对象不变量，并在一个事务中提交变更、逆操作、回执与事件。

同请求同输入返回原回执，新请求的陈旧修订产生冲突，同请求异输入产生明确错误。撤销重做按[共享历史与手势组](../reference/commands-and-tasks.md#undo-history)核对模型和历史前提，建立新修订。

**异常与恢复**

提交失败保持原工程有效状态。并发冲突保留用户草稿和候选，读取差异后重新准备。

[T09 验收场景](../testing/strategy.md#t09)。

<a id="req-10"></a>

## REQ-10 后台任务、取消与重启恢复

调用者开始、查询、取消或恢复后台任务时，系统持久保存输入、步骤依赖、执行器版本、预算、租约与检查点。

完整的成功步骤可复用，旧执行世代的结果被拒绝。取消停止派发并回收所属计算资源，恢复继承原预算和消费记录。

**异常与恢复**

服务中断或外部结果未知时，按原操作和原目标核对实际效果，再选择恢复动作。备份恢复先执行[外部任务恢复屏障](../reference/project-format.md#backup-recovery)，排队记录及费用继续按实际效果核对。

[T10 验收场景](../testing/strategy.md#t10)。

<a id="req-11"></a>

## REQ-11 缺陷、返修与分项复验

制作者标记具体对象、姿态或时刻的缺陷后，系统保存其来源和判据，生成返修候选，并在应用后重放原场景。

修复前后画面、采样和对象关系可以对应比较。数值检查与视觉评审各自更新对应判据。

**异常与恢复**

来源变化时重新准备受影响候选。视觉缺陷经对应版本的实际画面评审关闭。

[T11 验收场景](../testing/strategy.md#t11)。

<a id="req-12"></a>

## REQ-12 Web、MCP、CLI、SDK 契约等价

Web、MCP、CLI 与 SDK 调用同一制作操作时，入口统一映射到 CommandSpec 和应用服务。

输入输出、权限、副作用、修订、幂等、分页、事件和错误语义一致。列表按[集合与条目版本](../reference/commands-and-tasks.md#collection-pagination)校验续页和更新。长任务返回可查询身份，协议回执与任务终态分别表达。

**异常与恢复**

错误输入和断线重连走同一契约。调用者可用原请求查询结果，再决定后续操作。

[T12 验收场景](../testing/strategy.md#t12)。

<a id="req-13"></a>

## REQ-13 统一工作台与可访问编辑

制作者使用 Riloom Studio 时，可在同一工程会话中完成导入、制作、动作、物理、联调和交付。

默认编辑按[应用草稿流程](../design/studio.md#default-edit-flow)自动保存，顶栏应用当前会话完整草稿，一次应用形成一个工程撤销组。应用期间新增输入在结果确认后保存为后续草稿。

画布、对象树、属性、参数、时间轴与任务面板围绕当前编辑任务组织。键盘、数值输入、焦点导航、200% 缩放和减少动画偏好可用于关键流程。

**异常与恢复**

冲突、失败候选和禁用操作显示具体对象、原因与恢复入口。草稿按[独立版本与编辑代次](../reference/commands-and-tasks.md#draft-persistence)持久确认，刷新恢复已确认草稿与后台任务，保存状态对应当前编辑代次。

[T13 验收场景](../testing/strategy.md#t13)。

<a id="req-14"></a>

## REQ-14 插件、配方与能力协商

扩展开发者注册导入器、工位、检查器、导出器或追踪源时，宿主协商接口版本、能力、Schema、资源需求和许可范围。

声明式配方按有类型参数和有界步骤图组合已注册能力。受信任代码插件显式安装，在独立进程按扩展点返回候选、检查结果、交付结果或追踪流，由宿主按[对应契约](../reference/commands-and-tasks.md#plugin-results)验证和接入。

**异常与恢复**

版本不相容、输出损坏、超时或卸载时，停止相关派发，处理在途效果并释放所属资源。

[T14 验收场景](../testing/strategy.md#t14)。

<a id="req-15"></a>

## REQ-15 真实原生转换与保真检查

制作者选择原生转换时，适配器读取固定工程、素材、目标配置和容差，通过获准接口生成目标编辑工程及运行文件。

目标读取器可以回读 CMO3、MOC3 与依赖文件，像素、UV、遮罩、参数、关键形、曲线和动态层序按既定样本比较。

**异常与恢复**

不能表达的特性、许可条件或资源限制给出具体对象和可选处理。用户选择兼容方案后重新生成完整候选。

[T15 验收场景](../testing/strategy.md#t15)。

<a id="req-16"></a>

## REQ-16 VTS 身份、映射与有界联调

制作者将运行包安装到已登记的模型目录时，安装计划固定包身份、目标预期内容和配置差异，按[安装与更新契约](../reference/integrations-and-delivery.md#model-installation)发布完整包、回读并恢复中断操作。

制作者连接已运行的 VTube Studio 并选择模型后，系统绑定软件会话、模型和运行配置身份，按授权执行联调。

追踪输入、模型参数、表情、动作与快捷键使用明确映射。短时测试只接管选定通道，结束或取消时释放对应控制。

**异常与恢复**

换模型、断线或目标身份变化时停止旧目标派发，核对当前状态后重新绑定。

[T16 验收场景](../testing/strategy.md#t16)。

<a id="req-17"></a>

## REQ-17 可编辑工程及独立运行交付

制作者选择交付内容和格式后，系统展开必要依赖，分别组装编辑工程、离线 Web 运行包和目标软件运行包。

编辑包在新目录导入为独立工程，模型对象、素材与表现保持。单 HTML 包可在断网且制作服务关闭时播放，目标软件包包含模型、图集、表现与运行配置。

**异常与恢复**

素材缺失或依赖冲突时定位具体对象。完整候选通过对应检查后发布到独立目录。

[T17 验收场景](../testing/strategy.md#t17)。

<a id="req-18"></a>

## REQ-18 权限、输入边界与隐私

服务接收文件、工程包、浏览器请求、插件结果或外部调用时，系统按授权对象、信任边界和资源限额处理。

文件访问核对真实路径，解包和解码有界，浏览器写入经过同源与会话校验。本地客户端确认实际工作区服务身份，会话能力绑定当前启动、工程存储世代及授权范围。凭据使用专门存储，用户素材按授权范围传递。

**异常与恢复**

越界路径、恶意输入和授权失败返回具体原因，修正输入或权限后重试对应操作。

[T18 验收场景](../testing/strategy.md#t18)。

<a id="req-19"></a>

## REQ-19 性能、资源预算与取消回收

任务派发、实时预览和导出前，系统估算并管理 CPU、内存、临时磁盘、GPU、期限及可选外部费用预算。

固定参考负载达到测试方案中的响应和资源目标。阶段资源可释放，取消按宽限期回收所属任务树。

**异常与恢复**

预算不足时给出所需资源和可调整项，调整范围或预算后重新准备完整任务。

[T19 验收场景](../testing/strategy.md#t19)。

<a id="req-20"></a>

## REQ-20 开源治理、可复现构建与发行

维护者按同一发行集合分别完成材料许可、可复现构建、安装兼容和渠道一致性要求。各子项具有独立输入、结果和异常处理，父项按[T20 汇总场景](../testing/strategy.md#t20)核对完整发行流程。

<a id="req-20-1"></a>

### REQ-20.1 材料许可与分发范围

项目权利主体选择其有权许可材料的许可方案，软件发行负责人依据各材料的许可和用途核对分发集合与必要通知。

每项材料的许可或授权来自有权作出决定的主体，使用与再分发范围和发行内容对应。根许可与必要通知随相应发行集合提供。

**异常与恢复**

根许可缺失、材料用途超出授权或通知遗漏时，定位对应材料和用途。补齐决定、通知或调整分发集合后重新核对。

[T20.1 验收场景](../testing/strategy.md#t20-1)。

<a id="req-20-2"></a>

### REQ-20.2 可复现构建

构建维护者固定源码、依赖锁文件、工具链和构建配置，在两个干净环境执行构建。

比较两次构建的完整文件集合与可执行内容。时间戳或签名的允许差异由构建配置预先列明，依赖解析与构建输入保持对应。

**异常与恢复**

依赖解析不符、缺少输出或出现允许范围之外的内容差异时，定位实际输入与差异，修正构建来源后重新比较。

[T20.2 验收场景](../testing/strategy.md#t20-2)。

<a id="req-20-3"></a>

### REQ-20.3 安装与兼容

测试人员按发行支持矩阵，在干净环境安装对应平台的产物并执行文档中的入口和基础工程流程。

软件版本、架构与说明一致，所需依赖可以取得，创建和重开工程可完成。源码发行按其构建步骤取得可运行入口。

**异常与恢复**

缺失依赖、错误架构或入口失效时，指出受影响平台与具体条件，修正对应产物或支持配置后复验。

[T20.3 验收场景](../testing/strategy.md#t20-3)。

<a id="req-20-4"></a>

### REQ-20.4 发行与渠道一致性

发行负责人在许可、构建和安装子项满足条件后，使用已授权的渠道、版本与文件集合准备发行。

从渠道取得的对应版本与预定文件集合、平台、使用说明和发行说明一致。受控测试通道覆盖传播延迟和旧缓存情形。

**异常与恢复**

渠道指向旧版本、文件缺失或平台不符时，修正对应渠道对象并重新取得、比较该版本。

## REQ-22 版本化格式、备份与恢复

制作者保存、备份、恢复或升级工程格式时，系统使用显式格式版本和一致性存储规则。

未知可选扩展按[引用与编辑兼容规则](../reference/project-format.md#extension-compatibility)保留，未知必需扩展进入可检查的受限读取。活跃工程一致性备份可恢复到异目录，按[身份接替与恢复屏障](../reference/project-format.md#backup-recovery)保持唯一可写所有者，外部任务核对后续作。交换导入建立独立工程身份，格式升级保留源与映射。

**异常与恢复**

损坏数据进入只读恢复，截断备份给出具体错误。回收按[资源生命周期](../reference/project-format.md#resource-lifecycle)协调发布与引用登记，保护保留中的候选、任务和读取占用。
