# 许可与分发

面向贡献者、项目权利主体和发行负责人，说明已采用的许可范围、贡献接收及目标生态的分发条件。

## 1. 已采用的许可

[根许可](../../LICENSE)规定当前材料类型的适用范围，全文随仓库提供。

| 材料 | 许可或授权 |
| --- | --- |
| 自有源码、SDK、插件接口、构建脚本及工程配置 | [Apache-2.0](../../LICENSES/Apache-2.0.txt) |
| 自有设计与使用文档正文及设计数据 | [CC BY 4.0](../../LICENSES/CC-BY-4.0.txt) |
| 自有合成测试图形与最小示例 | [CC0 1.0](../../LICENSES/CC0-1.0.txt) |
| 项目标志图形 | 按根许可中的标志授权，用于介绍或链接 Riloom |
| 第三方依赖、字体、SDK、示例及法律文本 | 各自实际许可与必要通知 |
| 用户角色素材、品牌与商标 | 相应权利主体授予的使用、修改与分发范围 |

贡献接收采用 [DCO 1.1](../../DCO)。贡献者按材料类型提供相应许可范围，并保留第三方材料的实际条件。

## 2. Cubism 接入与分发组成

Cubism 制作转换、SDK 预览与编辑器控制分别列明实际接口、组件精确版本、适用协议版本、使用用途和发行文件集合。软件发行负责人按该集合核对授权条件与通知。

使用 SDK 并提供不定数量模型加载或生成功能的应用，在 D-NATIVE-01 中列明 Expandable Application 分类、对应协议版本、所需审核及发布步骤，按照适用协议取得相应用途和分发范围的授权。

接入按三类组成处理。

1. **独立核心与 Studio** 包含自有工程格式、求值、渲染、制作、离线播放器及其获准分发的依赖。
2. **VTS API 适配** 连接用户运行的软件，按会话授权操作选定模型。发行内容列明客户端代码及其许可通知。
3. **Cubism SDK 与制作适配** 按所选接口和组件版本明确用途、分发文件、协议及发布步骤。

自有材料许可依根许可执行，Cubism 接入与发布路线由 D-NATIVE-01 确定，分别对应[实施路线图](roadmap.md)中的分发组成。

## 3. 材料接收与通知

引入外部材料时，贡献者提供来源、适用许可、修改和可贡献范围，维护者核对实际接收与分发用途。必要版权、署名和许可通知随对应材料保留。贡献操作见[贡献指南](../../CONTRIBUTING.md)。

正式分发按实际文件集合核对根许可范围及第三方条件，源码、文档、图形和用户作品各按其适用许可处理。
