# 术语表

供文档作者、实现者和译者查询中英文概念、技术标识及适用语境。

## 领域术语

| 中文 | 英文或标识 | 含义与语境 |
| --- | --- | --- |
| 工程 | Project | 持久保存模型对象、素材关系、修订和扩展的制作单元 |
| 工作区 | Workspace | 管理工程登记、服务实例、布局和插件的本地范围 |
| 部件 | Part | 组织绘画与控制对象的分组 |
| 绘画 | DrawItem | 参与绘制、遮罩、显隐和层序求值的对象 |
| 网格 | Mesh | 由顶点、UV 和三角索引定义的可变形表面 |
| 纹理坐标 | UV | 顶点到源纹理或图集的二维映射 |
| 工作副本 | Working image | 采用已选颜色转换的制作像素，原始文件和原始解码另行保留 |
| 隔离组 | Isolated group | 子项先在透明背景合成，再作为整体进入父级的分组合成边界 |
| 控制器 | Controller | 对下属对象施加局部形变或旋转的控制对象 |
| 参数 | Parameter | 具有稳定身份、单位和取值范围的模型控制量 |
| 关键形 | Keyform | 指定参数坐标处的局部变形、透明度或层号取值 |
| 静止绑定 | Rest binding | 对象静止局部坐标到父控制静止局部坐标的可逆仿射映射 |
| 单纯形复形 | Simplicial complex | 通过显式连接定义稀疏关键形支持域及公共面的数据 |
| 动作 | Motion | 随时间变化的参数曲线、循环与事件 |
| 表情 | Expression | 选择后参与通道合成的表现状态 |
| 状态组 | VariantGroup | 定义衣装、嘴型、配件等选项与互斥关系 |
| 通道 | Channel | 参数或表现控制量参与合成时的作用位置 |
| 通道贡献 | Contribution | 某输入产生的模式、权重、优先级及拥有者 |
| 工位 | Station | 基于明确对象和输入契约执行的制作能力 |
| 配方 | Recipe | 用参数、选区和步骤依赖组合工位的配置 |
| 候选 | Candidate | 绑定来源修订、变更、素材和保护约束的制作结果 |
| 变更集 | ChangeSet | 以一次完整编辑提交的有类型操作集合 |
| 修订 | Revision | 工程提交后单调增加的状态序号 |
| 存储世代 | storageGeneration | 标识当前工程存储实例，备份恢复接替后更新，参与会话授权 |
| 回执 | Receipt | 关联请求身份、输入和实际操作结果的持久记录 |
| 任务 | Job | 具有步骤、预算、进度和终态的后台执行单元 |
| 任务检查点 | Job checkpoint | 已完成步骤的产物、依赖和调度恢复位置，见[任务契约](commands-and-tasks.md#5-持久任务与步骤) |
| 求值检查点 | Evaluation checkpoint | 完整求值步的时钟、随机调度、表现、输入与物理状态，用于[跳转重放](authoring-and-evaluation.md#evaluation-checkpoints) |
| 缺陷 | Defect | 绑定对象、姿态、时间和判据的待修复问题 |
| 评审 | Review | 对具体候选及判据作出的检查或画面判断 |
| 适配器 | Adapter | 连接导入格式、外部服务或目标软件的组件 |
| 追踪映射 | Tracking mapping | 将输入通道按范围与曲线连接到模型参数 |
| 交付包 | Delivery package | 按选定格式及依赖闭包组装的独立产物 |

## 名称与标识

Riloom 为项目品牌与原创仓库名，Riloom Studio 为工作台名称。包名按生态要求使用小写 riloom。

对象显示名、稳定对象标识和外部参数标识分别存储。追踪输入 MouthOpen 通过 mapping 连接到工程中的模型参数，界面翻译保持对应代码标识。

## 要求用语

| 中文 | 英文 | 用途 |
| --- | --- | --- |
| 必须 | MUST | 表达需求或契约中的必要行为 |
| 不得 | MUST NOT | 表达契约明确禁止的行为 |
| 建议 | SHOULD | 表达具有具体理由与替代条件的推荐方案 |
| 可 | MAY | 表达允许选择的行为或能力 |
