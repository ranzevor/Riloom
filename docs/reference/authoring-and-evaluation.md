# 制作能力与求值

供制作算法、求值器和渲染器开发者查询工位输入输出、表现合成、曲线、物理及缺陷修复规则。

## 1. 自由编辑与配方

每个工位是对明确对象和固定工程修订的操作。人工编辑、参数化规则及图像提供方都输出同一种 Candidate。候选包含可应用 ChangeSet、源身份、派生素材、保护约束、差异预览、数值诊断和视觉评审入口。

配方记录选区和对象引用，不包含角色专用脚本、固定表情名或外部绝对路径。用户可以复制配方、修改顺序、组合多个工位或只应用一个完整候选。任何部分应用都必须重新计算依赖和不变量。

| 工位 | 必要输入 | 结果与主要约束 |
| --- | --- | --- |
| 绘制准备/回位 | 原图、画框、可编辑和保护选区 | 全画框来源及回位映射；保护区像素检查 |
| 拼接检查 | 相邻绘画、连接边、姿态范围 | 缺口、重叠、接缝与遮挡诊断 |
| 拓扑 | 源轮廓、固定边界、密度目标 | 有效三角网格及 UV；材质保持 |
| 控制 | 父子对象、局部坐标、控制范围 | 无环层级、可逆编辑及所有权关系 |
| 关键形 | 参数坐标、变形目标、保护区域 | 局部关键形及多轴组合关系 |
| 连接 | 附着区域、父控制、相对运动范围 | 附着约束与覆盖轨迹 |
| 衣口分层 | 完整衣料、源纹素切线、前后保护选区、中间身体 | 后沿→身体→前沿；几何、UV、控制、遮罩和动作联动 |
| 行为 | 参数、曲线、状态组、混合规则 | 动作、表情、衣装和通道控制候选 |
| 物理 | 输入/输出、粒子、时步、外力和预热 | 可复现轨迹及预算内结果 |
| 返修 | 原缺陷、来源身份、修复配方、原采样 | 受影响对象修复及原场景复验 |

工位失败可以产生诊断和检查图，其应用操作集合必须为空。未完整处理的样本不能被写成候选数值通过。

<a id="paint-roundtrip"></a>

### 补画与素材往返

补画默认采用外部编辑往返。制作者选择绘画、可编辑选区与保护选区，执行“准备补画”，下载全画框 PNG 编辑副本与选区预览，自行编辑并保存，再通过“导入补画结果”选择本次准备和返回文件。准备阶段创建草稿与编辑产物，回导工位形成素材替换候选，提供最终画面、差异与应用入口。图像提供方在同一入口显式选择，沿既有出站、输入及费用授权处理，结果使用同一回位与保护流程。

准备以已应用工程为来源，所选对象须存在于基线。所选源素材或画框存在待应用修改时，界面提供“应用草稿”入口，完成后按返回修订准备。其他直接编辑草稿沿各自基线保存。每次准备新建独立补画草稿，保存 kind=paint、来源修订与状态身份、drawItemId、源 Asset 和工作像素引用、完整画框及源纹素原点、选区引用、输出像素格式和颜色配置。准备 PNG 与预览以不可变 ArtifactRef 发布并由该草稿保留。制作者另存的外部文件作为其可编辑副本，回导先将所选文件固定为不可变返回素材引用。

默认输出与工作画框采用 1∶1 纹素映射，PNG 使用 RGBA8 或 RGBA16，沿用能直接表达的源工作精度。其他工作像素格式先由制作者选择明确的精度转换配置。默认返回图保持登记的宽高、像素格式与工作颜色配置，原点取准备记录。格式、尺寸或配置不符时返回具体差异及空应用操作集合。提供方所需的缩放、裁切和格式变换在派发前固定，适配器按该映射还原全画框，再交宿主检查，回位的采样与舍入规则随提供方适配配置保存。

可编辑选区 E 与保护选区 P 保存为同尺寸二值源纹素掩码，实际替换区域为 E∖P，保护选区优先。几何选区按像素中心与偶奇填充规则栅格化，中心恰在边界上时计入选区。组装结果在实际替换区域使用已校验返回像素，其余纹素逐通道复制源工作副本，包括低 Alpha 描边及 Alpha=0 的 RGB。保护及不可编辑区域在返回图中的变化列入差异，预览显示最终组装结果。最终组装沿用源工作像素格式，编辑区域按选定转换映回该格式。颜色转换遵循[颜色契约](project-format.md#color-management)，转换选择和像素格式在回导前固定。

回导按 expectedDraftVersion 核对 editing 状态，保存新的派生 Asset、完整 ChangeSet 与素材引用，递增 draftVersion，并在同一工程元数据事务登记绑定该版本的 Candidate。替换只更新所选 DrawItem 的素材引用，其他共享源 Asset 的绘画保留原引用。相同全画框保持原网格、UV、局部关键形、父控制、分组、遮罩与动作，工程修订在候选应用时推进。

多个准备使用独立草稿并行。回导与应用分别核对草稿版本和当前模型前提，同请求重投返回原结果。来源修订变化时保留返回素材、草稿和候选。重新准备先取得当前修订，逐项核对所选对象的源素材、画框、颜色配置、选区及依赖关系，条件相同可复用原返回素材并生成新候选，条件变化时先展示来源差异，再按制作者选定的新范围准备。

丢弃补画草稿按其版本终结并阻止后续回导发布与应用，同时向所属在途任务登记取消意图。迟到结果按任务与终结草稿核对，已应用补画通过工程撤销恢复。外部可编辑文件由制作者管理，已导入返回素材与自有产物按现有保留引用和回收规则管理。

## 2. 衣口及连接的通用化要求

前后层在源纹素空间划分，重组后保持受保护的可见 RGBA。保护选区可覆盖花边、描边和低 Alpha 细节。源素材保留，前后派生素材以不可变引用登记，后续配方消费实际分层来源。

克隆几何时同步 UV、局部关键形、同源遮罩、父控制和分组归属。身体使用工程中的实际对象及其遮挡关系，检查范围包括相关绘画和全部祖先控制。动态层号求值在相同姿态执行。

采样集合包括所选范围边界、相关轨道的全部关键坐标、相邻坐标中点、曲线极值、阶跃两侧及已知缺陷时刻。组合参数沿声明的轨迹和覆盖规则取样；自适应细分记录误差与最大步长。预算不足时返回完整性失败及未覆盖集合，不静默删样本。

返修沿原缺陷的来源、身体、前后层和采样范围重新检查；数值结果与 visualReview 分开。新候选的视觉状态初始为 unreviewed。

## 3. 表现与通道仲裁

表现系统用状态组、参数通道、权重和混合规则表达，角色名称和参数名称不参与核心判断。

1. 从 Parameter 默认值建立基础状态。
2. 状态组确定选定表情、衣装、嘴型和允许参与的通道。
3. Motion、Expression、Tracking、Manual 各产生带稳定身份、值、模式、权重、优先级和拥有者的 Contribution。
4. 按[混合算法与权重](#channel-mixing)合成各通道，执行已登记的归一化和替换冲突规则。
5. 输入约束与限幅确定本时步的物理输入，按固定时步推进物理；依赖环通过显式上一时步反馈表达，禁止同帧隐式循环。
6. 物理输出按通道拥有权合成并限幅，再求值关键形、控制层级、网格、透明度、遮罩与绘制顺序。

<a id="channel-mixing"></a>

### 混合算法与权重

通道持久保存 mixAlgorithm 与 replaceConflictRule，首版算法为 riloom.channel-mix/1。每项 Contribution 具有稳定 contributionId、目标参数、value、mode、weight、priority 和 owner，可另带 normalizationGroupId。value 使用有限数值，weight 在 [0,1] 内，priority 为安全整数，同一步中的 contributionId 唯一。校验后剔除零权重贡献。

同一通道按 priority 升序处理，高优先级后作用。每个优先级内依次执行 replace、multiply、add，每类内部按 contributionId 的 UTF-8 字节序升序执行。公式中的 x 为当前值，v 为贡献值，w 为处理后的权重。

| 模式 | 单项公式 | value 的单位 |
| --- | --- | --- |
| replace | x ← (1-w)×x + w×v | 参数的绝对值 |
| multiply | x ← x×((1-w) + w×v) | 无量纲倍率 |
| add | x ← x + w×v | 参数单位的增量 |

归一化组限定在同一通道、优先级和模式内。组策略 keep 保留原权重，cap-at-one 在总权重超过 1 时将各权重除以总和，总权重在 [0,1] 时保持原值。未分组贡献使用原权重。所有总和及后续运算均按上述稳定顺序用双精度计算。

同优先级存在多个有效 replace 时，replaceConflictRule 为 reject 则返回具体贡献冲突，ordered 则逐项执行单项公式，blend 则先算总权重 W 与加权目标 V=Σ(w×v)/W，再令 x ← (1-min(1,W))×x + min(1,W)×V。空集合保留 x，单项使用单项公式。通道默认使用 reject，ordered 与 blend 随工程配置明确保存。

物理前合成以参数默认值开始，物理后合成以前一阶段结果开始，并按输出拥有权纳入物理贡献。参数限幅在既定的两个阶段边界执行。数值溢出、非法权重和重复贡献标识返回具体输入错误，输入配置与混合算法版本进入求值身份。

追踪输入与模型参数各有 ID。mapping 定义 inputId、outputParameterId、输入/输出范围、方向、曲线、死区、平滑和用途。MouthOpen 与任意自定义模型参数通过显式映射连接；名称相同或不同均不替代映射检查。

表情区分嘴角形状、开口量和嘴型状态。某表情是否接管开口量由其通道契约决定。嘴型选择组允许设置“进入表情时使用默认嘴型”和“用户切换覆盖至何时”；两套绘画的互斥和开合分别验收。快捷键只触发状态动作，标签来自同一个动作目录。

单次动作结束或取消时退出其拥有的通道，恢复当前选定状态和持续输入。不同衣装的显隐、动作参与和物理组选择由 VariantGroup 定义。

## 4. 关键形、曲线与物理

关键形与父控制使用[确定性几何算法](#deformation-algorithms)，重布网按[来源映射与保留方式](#remesh-mapping)同步处理全部关键形、UV 和祖先控制影响。

<a id="deformation-algorithms"></a>

### 控制与关键形算法

首版几何语义为 riloom.deformation/1。每个对象显式保存算法版本、模式及解析后的配置，浮点使用双精度，基础值与关键形数组形状一致。各关键形集合写入互不重叠的属性块。网格顶点和 Warp 节点的关键形值表示相对静止数据的位移，Rotate 的中心、平移和展开角以及 Alpha、drawOrder 使用完整属性值。没有集合的属性使用基础值。对象引用、拓扑和布尔选择由编辑操作、状态组或阶跃轨道表达。

**绑定与控制顺序**

每个几何对象保存一个父控制引用及可逆仿射绑定矩阵 B，默认单位矩阵。B 将对象静止局部坐标映射到父控制的静止局部坐标。画布映射 W₀(x)=x，控制器世界映射 Wc(x)=Wparent(Bc×Dc(x))，网格世界顶点为 Wparent(Bmesh×(v⁰ᵢ+Δvᵢ))。求值依次执行网格局部关键形、网格绑定、最近父控制及其绑定，再逐级向外。控制树与分组合成树分别保存。同一参数可驱动多个对象，悬空父控制、层级环、不可逆绑定和数值溢出返回具体诊断。

Rotate 使用 DR(x)=p+t+R(θ)(x-p)，R(θ)=[[cosθ,-sinθ],[sinθ,cosθ]]。默认 p=t=(0,0)、θ=0°，正 90° 将 (1,0) 转为 (0,1)。角度按保存的展开数值插值，350°→10° 中点为 180°，跨零点短转保存为 350°→370°。三角函数计算前将角度约减到一个周期，持久值保持展开角。

Warp 使用规则矩形笼的固定三角片线性位移。笼保存 x₀、y₀、有限正宽高、至少 2×2 的行列数及逐行节点位移，默认位移为零。点 x 夹紧到笼得到 z，定位单元及单元内坐标 s,t∈[0,1]，固定对角线为左上→右下。

~~~text
s >= t  使用 00、10、11，权重为 (1-s, s-t, t)
s <  t  使用 00、11、01，权重为 (1-t, s, t-s)
DW(x) = x + Σ βk(z) × Δck
~~~

格线点使用右侧或下侧单元，最右或最下边界使用最后单元。边界外沿用夹紧位置的位移并加到原 x，零位移笼在全域为恒等。零宽高、节点数量不符和非有限节点拒绝。变形笼可折叠或压平，前向映射继续按公式求值，零面积三角形无覆盖面积。世界坐标反求局部坐标或保持选定姿态重绑定时，保存附着分片。不能唯一定位时返回对象级冲突并保留原关系。

**规则多轴模式 grid-linear**

集合保存有序活动轴、每轴严格递增且位于参数范围内的关键坐标，以及完整笛卡尔积的关键形值。每个活动轴至少两个坐标，零轴为一个固定值。轴数、角点数与数组大小按预算校验。参数通道限幅后，轴 j 所在区间的比值 tj=(qj-aj,k)/(aj,k+1-aj,k)。角点 b 的权重为 Πj(bj×tj+(1-bj)×(1-tj))，结果为各角点属性值的加权和。角点按 Σj bj×2ʲ 升序累加，轴列表首项对应最低位。默认域外策略为 reject，显式 clamp-axis 时夹紧到各轴关键坐标范围。缺角点返回输入错误，改用稀疏模式由明确编辑完成。

**稀疏模式 simplex-linear**

集合保存关键形点与显式单纯形连接，每个 d 维单纯形包含 d+1 个点。顶点按关键形 ID 的 UTF-8 字节序排序，以 E=[x₁-x₀,…,x_d-x₀] 求 λ₁…λd=E⁻¹(q-x₀)，λ₀=1-Σλᵢ，输出为 ΣλᵢFᵢ。权重和属性按该顶点顺序累加。

活动轴的参数范围必须非零。归一化坐标为 zⱼ=(qⱼ-minⱼ)/(maxⱼ-minⱼ)，用于退化检查和最近点距离。归一化边矩阵 Eₙ 的各列 eᵢ 要求非零且 det(Eₙ)²>2⁻⁸⁰×Π|eᵢ|²，快速路径按列缩放并单位化，比较单位列矩阵的 |det U| 与 2⁻⁴⁰，误差界不能判定时按原 binary64 精确值比较原不等式，耗尽预算返回 RESOURCE_LIMIT，平方与连乘保持缩放或精确表示。重复点、退化或低于该相对阈值的单纯形拒绝。复形内部互不重叠，交集只能是共同顶点构成的完整公共面。包含、相交及边界符号以原参数坐标的精确方向谓词判定，双精度过滤不确定时回退精确算术，耗尽算术预算返回 RESOURCE_LIMIT。公共面选择单纯形 ID 字节序最小者，面外顶点的精确零权重置零。权重按固定主元选择和消元顺序求解，主元绝对值同值时取原行号较小者。

默认支持域外策略为 reject，包含复形内部空洞。显式 nearest-key 时按归一化平方欧氏距离选择已有关键形，同距离按关键形 ID 排序，回退选择随工程保存。该回退在最近点分界处发生阶跃。零轴沿用单固定值。Alpha 值在 [0,1] 内，层号为有限实数，均参与相同插值与稳定排序。

<a id="remesh-mapping"></a>

### 重布网对应与保留方式

每个新顶点保存源网格身份、源顶点索引或源三角索引及重心权重 β。来源定位使用未变形几何，权重非负且和为 1。新静止顶点、UV 和每个局部关键形位移分别为对应源值的 Σβr×valueᵣ。来源三角形歧义由显式附着消除，UV 接缝保留独立顶点，退化来源片保留原连接并不承担新顶点的重心定位。返回的新网格、全部映射与关键形共同构成完整 ChangeSet。

默认 preservationMode=exact。新三角形各自位于同一旧三角形内，完整覆盖源表面且内部无缺口或重叠，跨旧边的新片先沿旧边分割。每个源片内新片按局部索引排序，源片之间保持原三角索引顺序。全部关键形值形成局部位置外包范围，沿各级绑定和 Rotate 以向外舍入的区间运算传播，旋转范围包含角区间端点和三角函数极值。遇到 Warp 时要求范围可证明位于同一仿射分片，整个支持域内零位移的笼直接通过。证明覆盖整个声明支持域后，候选标记 exact。失败定位源三角形、祖先控制与跨越分片，应用操作为空。

制作者可显式选择 preservationMode=sampled，保存姿态/轨迹范围与完整采样配置，默认位置容差 0.01 像素、UV 分量容差 10⁻⁶。新旧表面按来源面片核对覆盖，接缝或几何重叠导致来源歧义时要求明确附着，避免跨表面合并。对每个样本先计算新旧网格顶点经过完整控制链后的世界位置，再在共同静止来源域中将新旧三角形交叠分割。每个交叠顶点分别用所在新旧静止三角形的重心权重，插值已变形的三角形顶点位置及 UV，比较对应结果。各片中的差值为仿射函数，其范数最大值取交叠顶点，记录最大误差及对应来源与姿态。未覆盖样本、表面缺口或超容差时失败。通过项保存 sampled 模式及实际检查范围。纹理与保护像素沿原引用保留。

### 算法身份与兼容

绑定、笼分片、轴顺序、关键点、连接、回退、重布网来源及保留方式进入模型状态。共同数学内核的版本固定算术顺序、方向谓词、区间舍入及三角函数实现，并进入求值与检查点身份。语义结果或回退规则改变时分配新算法版本，已有工程按原版本求值，迁移通过显式候选完成。V-RENDER-01 验证本节既定语义、独立算例及预算，具体实现版本随发行锁定。

曲线保留 Bezier 手柄、插值、循环和离散事件。修改端点值不等同于替换整条曲线。随机待机使用有版本的调度算法、种子、片段权重、冷却、进入/退出状态和包络限制；同种子及相同输入轨迹可重放。

物理采用固定 dt，渲染可插值。dt、子步、预热、初态、随机种子和外力轨迹参与求值身份。seek 按[求值检查点与跳转](#evaluation-checkpoints)重放到目标时刻。交互落后时给出实时性状态，离线验收按完整时步执行。

<a id="particle-chain"></a>

### 有根粒子链物理

首版求解器为 riloom.particle-chain/1，使用双精度半隐式 Euler 预测与根到叶长度投影。一个系统保存按根到叶排序的粒子链，0 为固定根，第 i 个自由粒子的父节点为 i-1。多个系统按 systemId 的 UTF-8 字节序求值，系统间反馈使用上一完整时步。每系统的固定坐标轴与工程一致，距离为像素、时间为秒、角度为顺时针度。

默认 dt=1/120 秒、substeps=1、warmupSteps=120、重力 g=(0,980) 像素/秒²、风加速度 w=(0,0)、阻尼 d=4 秒⁻¹、回正系数 k=16 秒⁻²。dt 为有限正数，substeps 为正安全整数，warmupSteps 为非负安全整数，d 与 k 为有限非负数，配置按任务预算校验。UI 输入预热秒数时向上换算为完整步数，保存 warmupSteps 并显示实际时长 warmupSteps×dt。每个自由粒子保存非零静止向量 rᵢ、阻尼 dᵢ 与回正系数 kᵢ，其长度 Lᵢ>0，系统解析和持久保存全部默认值。

输入映射在子步结束时刻取得混合后的根位置 a、驱动角 θ、重力与风，输入单位及限幅显式保存。h=dt/substeps，时刻由完整步号和子步号计算。令 R(θ) 为工程坐标中的顺时针旋转矩阵，驱动静止位置 bᵢ=a+R(θ)×Σⱼ₌₁ⁱrⱼ。根的新位置固定为 a。所有自由粒子先从本子步旧状态 pᵢ、vᵢ 同时计算预测值。

~~~text
accᵢ = g + w + kᵢ × (bᵢ - pᵢ)
v*ᵢ = (vᵢ + h × accᵢ) / (1 + dᵢ × h)
qᵢ = pᵢ + h × v*ᵢ
~~~

随后按根到叶处理，Dᵢ=qᵢ-p'ᵢ₋₁。若 |Dᵢ|>εᵢ，令 p'ᵢ=p'ᵢ₋₁+Lᵢ×Dᵢ/|Dᵢ|，否则使用驱动静止方向，令 p'ᵢ=p'ᵢ₋₁+R(θ)rᵢ。εᵢ=10⁻⁹×max(1,Lᵢ) 像素。投影只调整当前子节点，已处理的父节点保持本子步结果。最后 v'ᵢ=(p'ᵢ-pᵢ)/h，根速度按根的新旧位置差计算。各系统均完成后再发布这个完整子步，溢出或非法值使本次求值失败，保留最近完整状态。

默认初态为输入起点的 pᵢ=bᵢ、vᵢ=0。显式初态保存各粒子位置和速度，并核对链长及根位置。预热固定起点输入，每个 warmupStep 包含全部 substeps，实际预热时长为 warmupSteps×dt。预热完成后模型时钟为 0，动作事件与外部控制保持起点消费位置。检查点保存链位置、速度、驱动根与角度、步号、子步位置，以及已完成预热完整步和当前子步，接续时沿用相同计数单位。

输出可选某粒子相对 bᵢ 的 x/y 位移，或当前边 p'ᵢ-p'ᵢ₋₁ 相对驱动静止边 R(θ)rᵢ 的有符号角。两条方向先单位化，再由 atan2(cross,dot) 计算角并转换到 [-180,180) 度，+180 归为 -180。映射使用 output=offset+scale×raw，单位、目标参数、模式、权重和优先级保存，默认 add、weight=1、priority=0，再按既有通道拥有权合成与限幅。输入输出引用形成同帧环时拒绝，显式上一时步反馈沿既有规则执行。

显示请求指定 hold 或 segment-angle，默认 hold，使用最近完整步。segment-angle 使用同一轨迹中包围目标时刻的两个完整状态。根位置和展开驱动角 θ 按时间权重 α 线性插值，各边的绝对方向按最短圆弧插值，恰好相差 180° 时取顺时针方向，再按固定链长从根逐级重建显示位置。由显示根与 θ 计算 bᵢ，再求位移、边角和通道输出。方向 179°→-179° 的中点为 180°，原始角输出按既定区间表示为 -180°。显示时间与状态时刻一并返回，插值不回写速度或求解器状态。

实时输入只足以取得较早状态时显示该完整状态及实际时间。离线插值需取得右侧完整步所需输入，轨迹缺项按检查点重放合同处理。

<a id="evaluation-checkpoints"></a>

### 求值检查点与跳转

求值检查点使用 riloom.evaluation-checkpoint/1，保存完整求值步结束后的可重建状态，独立存于模型状态之外。[任务检查点](commands-and-tasks.md#5-持久任务与步骤)负责步骤产物与调度恢复。

| 状态组 | 必需内容 |
| --- | --- |
| 来源与兼容 | 工程来源修订、模型状态身份、求值器及各算法版本、混合配置、初态、预热、时步和已消费输入前缀 |
| 时钟 | 求值时间，各物理系统的已完成步号、子步计数及时间累积余量 |
| 随机调度 | 每条随机流的算法、内部状态和消费位置，活动片段、调度队列及冷却期限 |
| 表现与输入 | 当前状态组选项、覆盖期、活动动作实例、循环位置、渐入渐出包络，通道拥有权及输入平滑状态 |
| 物理 | 粒子位置、前一位置或速度、求解器累积量、上一时步反馈、滤波输入输出及已完成预热进度 |
| 轨迹与事件 | 已授权参数级输入轨迹的不可变分段引用、消费位置、同时间事件顺序及已消费事件游标 |

兼容判断使用模型状态身份、求值器与算法版本、初态和运行配置、时步及已消费输入轨迹的有序内容。轨迹引用与消费游标共同定位已消费前缀，游标之后追加输入时沿用原检查点。来源修订用于定位工程。模型、混合规则、曲线、物理设置或已消费输入前缀变化后选择新身份下的检查点，布局和视口缩放沿用原身份。

seek 选取时间不晚于目标且身份匹配的最近完整检查点，恢复各状态组后按原输入顺序推进完整时步。目标时刻的剩余显示相位使用选定的显示规则，物理按[粒子链显示模式](#particle-chain)取完整步或方向插值。检查点缺失或失效时，从登记初态和相同预热过程重算。损坏或缺字段的条目返回具体诊断，完整输入可用时从初态重算，必需输入缺失时停止本次重放并列明缺项。

动作、冷却、覆盖期和包络时间使用模型时间，随求值时钟推进。检查点发布先完成所有状态和引用写入，再更新可用索引。运行中的求值任务保留所用检查点及输入引用，失效条目按既有引用闭包回收。seek 中的离散事件重建内部求值状态，外部控制由当前显式联调命令执行。随机流恢复内部状态与消费位置，预热按已完成进度续接。

## 5. 渲染与缺陷

求值结果包含顶点、UV、工作纹理、颜色、Alpha、分组合成树、遮罩依赖图及各级稳定排序。renderer 按[颜色](project-format.md#color-management)与[合成契约](project-format.md#compositing-and-masks)消费这些结果，保留隔离组边界并按依赖计算遮罩覆盖率。GPU 纹理按内容身份复用，对象删除、工程切换和 context loss 都有释放或重建路径。网格线、控制点、保护区域和诊断叠层属于视口显示配置。

Defect 绑定工程修订、对象集合、参数姿态/时刻、输入轨迹、截图及判据。修复创建新的候选和复验记录，缺陷关联修复前后的画面。关闭视觉缺陷需要对应版本的实际视觉评审；通过数值规则只能更新其数值检查项。
