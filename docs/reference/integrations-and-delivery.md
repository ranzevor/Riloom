# 软件适配与独立交付

供适配器与导出模块开发者查询导入、目标软件连接、转换和交付包的契约。

## 1. 能力拆分

| 能力 | 提供方责任 | 成功产物或观察 |
| --- | --- | --- |
| PSD 导入 | 解码图层、画框、分组、遮罩和色彩配置，按[图像契约](project-format.md#color-management)匹配合成语义 | 原始文件与解码像素、明确颜色转换的工作副本及逐特性导入结果 |
| Cubism 制作转换 | 使用允许该用途的制作接口生成真实格式 | 可回读的 CMO3、MOC3 与依赖文件 |
| Cubism SDK 预览 | 在对应许可及版本范围内求值和显示 | 原生数值与画面对照 |
| Cubism Editor 控制 | 官方公开接口实际提供的控制能力 | 对目标打开工程的实际回读 |
| VTS 联调 | 身份、追踪、表情、热键、动作及性能观察 | 实际目标状态和有界测试回执 |
| 图像提供方 | 按获准输入与预算处理指定图像 | 产物、提供方版本、来源和费用记录 |

这些能力分别发现和启用。渲染 SDK 的存在不能被用作制作编译能力；制作接口与软件控制接口分别验收。

分组导入保留隔离合成边界与组透明度阶段，嵌套遮罩按[源覆盖率依赖](project-format.md#compositing-and-masks)核对。PNG 与 PSD 的原始色彩配置、工作副本及转换选择共同进入素材引用，超色域处理按同一颜色契约执行。无法等价表达的分组、混合或遮罩先给出具体差异，制作者选择的烘焙和转换作为完整候选应用。

外部补画采用制作者下载并手动编辑的全画框 PNG，回导文件与提供方结果共用[回位、保护与素材替换合同](authoring-and-evaluation.md#paint-roundtrip)。提供方适配在发送前固定尺寸/格式变换及回位配置，宿主使用最终全画框像素检查保护区域和派生引用。

## 2. Cubism 转换设计

转换器输入固定 ProjectState、内容地址素材、目标 profile 和容差配置；输出先进入本任务候选目录。适配器报告目标版本、工具身份、许可条件、支持特性、不能表达的对象及资源预算。

Cubism 制作适配通过具有明确使用许可和维护契约的接口实现。转换插件在进入发行清单前完成接口支持、依赖版本与许可核对。交换流程支持将工程导入目标编辑器，完成转换后返回产物及实际处理结果。

完整转换检查：

1. 导出前检测参数、联合关键形、变形器、遮罩、图集、混合及动态层号的表达能力。
2. 生成可编辑目标工程，使用目标读取器回读；再生成真实运行文件。
3. 以已选工作副本及输出颜色配置核对图集可见 RGBA、UV、遮罩采样阶段、分组合成边界、参数与稳定层序。原始素材字节保留另行检查，颜色转换按独立参考比较。
4. 对固定的参数、动作、物理和边界采样比较源与目标求值；转换差异逐对象列出。
5. 使用实际目标软件检查表情、嘴型、衣装、追踪、循环、回位和画面。
6. 通过各必要项后发布该候选的完整文件清单。

目标容差来自模型像素单位及既定视觉要求，在转换前锁定。适配器可拒绝不能表达的特性，也可提出带具体损失的降级候选；用户选择后重新生成和验收。运行文件不得以占位二进制或模拟结果代替。

## 3. VTS 连接与控制

通过公开 API 连接用户已运行的软件。首次授权沿 VTS 提供的机制完成；令牌存系统凭据设施或用户权限限制的本地存储。测试不主动抢占桌面焦点。

绑定身份包括软件版本、会话、ModelID、运行包摘要与登记配置。每次副作用执行前回读实际模型，换模型或断线停止向旧目标派发。原生操作的发送、回执与实际回读各有记录；toggle 型动作结果未知时先核对状态。

运行配置从 Project 的行为与追踪映射生成。UI 名称、动作 ID、快捷键和目标文件映射来自同一目录。互斥组、默认状态和退出恢复均在目标软件验证。短时参数测试声明所接管通道，结束或取消只恢复本次拥有且仍归本次控制的输入。

### 模型安装与更新

riloom.target.install 使用 workspaceId、requestId 和固定安装计划。计划包含已授权安装根引用、目标相对目录、来源运行包身份、目标预期完整文件清单及本地配置的保留或替换选择。首次安装要求目标目录不存在，更新绑定已登记且归属明确的原包。来源包、配置选择与目标前提共同固定为本次请求输入。

安装锁以已核验真实父目录与规范化目标名称定位，首次安装和更新共用同一锁键。每个目标由一个安装者持有系统排他句柄，竞争者返回 TARGET_BUSY。暂存区与旧包保留区位于已授权的同一文件系统，并处于目标软件的模型扫描范围之外。目录发布采用目标不存在时的改名操作，文件访问沿用[文件授权规则](../security/design.md#3-文件与解析)。

1. 在工作区事务中登记原操作、任务与安装意图，固定来源、预期目标、暂存目录和旧包保留位置。受理回执按通用任务契约返回。
2. 在本次自有暂存区组装完整包，按计划复制选定的本地配置并形成最终安装清单，核验文件集合、字节和依赖，完成平台支持的文件和目录持久化步骤。
3. 切换前确认目标软件已关闭或该模型已卸载，检查文件占用，重新核对目录归属和目标完整内容。正在使用或被占用时返回 TARGET_BUSY，目标变化时返回 TARGET_CHANGED。卸载与后续加载按各自授权执行。
4. 更新时将原目录改名至本次保留位置，核对移出后的旧包仍与预期一致，再将完整暂存目录改名至目标位置。首次安装直接发布暂存目录。两次改名之间目标可暂时缺席，操作保持执行中。
5. 从最终目标回读完整文件清单、包身份和配置，再持久保存最终安装结果并关联原受理回执。结果给出实际已安装包、旧包保留引用及各阶段状态。模型加载与表现检查按 T16 取得各自结果。

每个改名阶段记录安装意图的完成位置。中断后读取原意图与当前任务终态、取消状态，核对目标、暂存和保留目录的实际内容后恢复。

| 当前实际状态 | 恢复动作与结果 |
| --- | --- |
| 目标仍为预期旧包 | 重验当前授权、取消状态、占用和内容前提后继续原操作，完整暂存结果复用 |
| 目标目录不存在且保留位置有完整预期旧包 | 将该旧包回置原位并核验，原安装返回失败及旧包已恢复结果 |
| 目标目录不存在且属于首次安装 | 完整暂存包通过当前取消状态和原前提校验后继续发布，缺失或损坏暂存结果返回具体失败 |
| 目标为完整新包 | 补齐回读和原操作结果，返回同一安装包身份 |
| 目标或保留目录出现计划外内容变化 | 返回 TARGET_CHANGED，保留可恢复目录与具体差异，后续操作依据当前内容重新准备 |

旧包移出后若核对失败，目标目录仍不存在且目录归属有效时将刚移出的原目录回置，并返回冲突。发布因占用失败时先按表核对旧包和目标。原位目标被其他写入者占用时保留自有目录与恢复入口。

取消在首次改名前停止后续派发并清理自有暂存。原目录已移出且目标目录仍不存在时，按归属和内容前提回置旧包。新包已完整发布时核对并记录实际包身份。目录冲突进入 reconciling，按当前内容与取消意图处理。核对完成且自有计算资源回收后保存对应终态与实际安装包身份，已持久完成的安装返回原结果。

同请求同输入返回原受理回执和同一 jobId，安装阶段与最终结果通过原任务查询。同请求异输入返回 REQUEST_ID_REUSED。恢复旧包使用新的安装请求，明确选择保留包并核对当前目标内容。安装故障注入使用隔离测试根目录。

## 4. 交付物

| 交付物 | 内容 | 独立验收 |
| --- | --- | --- |
| 编辑工程 | .riloom.zip、素材、Schema、来源和许可引用 | 新目录导入后对象、像素和表现保持 |
| 离线 Web 运行包 | 单 HTML 播放器及嵌入的模型数据和素材 | file:// 打开、断网、制作服务关闭仍能播放与控制 |
| 目标软件运行包 | 真实模型、图集、表情、动作、物理及运行配置 | 目标软件加载、功能、性能和画面 |

单 HTML 导出将可信播放器代码与非执行模型数据分别编码，转义脚本结束标记并使用固定 CSP 摘要；模型内容不得变成脚本。导出需要计入编码增量和浏览器内存预算；不能在文件打开后偷偷依赖 localhost、远端 CDN 或开发控制服务。目标软件运行包只包含运行依赖；MCP、Web、内部诊断和开发控制脚本留在制作环境。

## 5. 发布与组装事务

交付选择按引用闭包展开必要素材、遮罩、祖先控制、参数、动作和物理；冲突或缺失停止组装并列出具体对象。构建写入新的 staging 目录，完整校验后发布独立的不可变候选目录。重试返回原产物或生成明确的新版本，不覆盖已交付目录。

各交付物包含清单、资源摘要、构建器和适配器版本、必要通知及使用说明，存放位置按交付形式确定。

| 交付形式 | 清单、通知与说明的位置 | 资源定位 |
| --- | --- | --- |
| 编辑工程交换包 | 包内 manifest.json、素材授权记录 rights.json 和使用说明 | 按包内相对引用定位模型与素材 |
| 单 HTML 运行包 | 清单、版本信息、通知与使用说明内嵌于同一 HTML，清单与模型使用非执行数据块 | 清单中的逻辑资源名解析到该 HTML 内的模型和素材 |
| 目标软件运行包 | 发行清单、必要通知与说明随运行文件提供 | 按包内相对引用定位模型、图集和运行配置 |

单 HTML 导出将资源清单、各内嵌资源的摘要、说明与通知一并嵌入。资源摘要对应清单所列模型、素材与播放器资源的原始字节。复制该文件到新目录后可独立读取和播放，播放器按清单定位同一文件中的资源。

许可、结构、数值、目标软件与视觉检查按各自判据记录。作品权利主体或其授权验收者确认采用后，登记对应包身份。后续改动产生新候选。
