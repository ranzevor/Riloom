# 安全、隐私与资源

面向服务、解析器、插件和适配器开发者，定义信任边界、授权、输入处理和资源控制。

## 1. 信任边界

| 输入或主体 | 默认权限 | 主要控制 |
| --- | --- | --- |
| 本地创作者 | 已选择工程内的制作操作 | 工程作用域、事务、恢复 |
| MCP / CLI 客户端 | 当前会话授予的工程能力 | 每请求校验作用域与副作用类别 |
| 导入的 PSD/工程包 | 数据 | 有界解析、格式校验、路径与资源限制 |
| 声明式配方 | 已注册工位组合 | 有界 DAG、类型约束、无任意代码 |
| 代码插件 | 用户显式信任的软件 | 安装授权、独立进程、来源版本、可停止 |
| 外部生成服务 | 明确选择的输入和费用范围 | 出站授权、预算、凭据隔离 |
| 目标软件 | 明确绑定的模型 | 身份回读、通道拥有权、操作回执 |

首版不执行不受信任代码插件。同一用户权限下的子进程可以访问该用户资源；子进程用于崩溃和生命周期管理。将来支持不受信任代码时，必须增加并验证平台级文件/网络/进程限制。

## 2. 本地服务

HTTP 仅绑定回环地址，精确校验 Host 和 Origin，拒绝空 Origin 的浏览器写入、跨站请求与 DNS rebinding。CLI/MCP 使用用户权限限制的 Windows 命名管道或 Unix socket。发现信息、操作系统对端与工作区锁持有者按[IPC 握手](../reference/commands-and-tasks.md#local-ipc)核对，随后建立有作用域的会话能力。发现信息和启动随机数用于定位与绑定，命令授权来自当前有效的客户端授权。

浏览器启动链接携带短期单次引导凭据于 URL fragment；客户端交换成功后立即清除 fragment。服务建立 HttpOnly、SameSite=Strict 会话 cookie，写请求另带 CSRF token 并校验同源。凭据不放入查询参数、访问日志、事件 URL或工程包。SSE 使用受保护的同源连接。

Studio 采用严格 CSP，禁用工程输入中的脚本及任意 HTML；导入的 SVG 在受限流程栅格化或按安全子集解析。生产页面不开放开发调试端点。

## 3. 文件与解析

文件授权以真实根目录和已登记逻辑引用为准。处理路径时检查绝对路径、..、符号链接/重解析点、UNC、盘符、Windows 保留名、大小写与 Unicode 冲突；执行前重新核对实际对象。文件打开使用平台允许的防跟随机制，输出写入自有新目录。

解包限制压缩比、总解压大小、条目数量和单文件大小，重复规范化路径拒绝导入。图像解码限制尺寸、图层数、内存估算和时间；解码器子进程可以被终止。JSON Schema 限制深度与复杂度，外部 $ref 不联网解析。

内容日志按技术用途记录摘要及必要元数据。源素材、提示词和截图属于工程数据，默认不上传、不进入公共测试或发行材料。错误信息不暴露凭据和无关本机路径。

## 4. 计算与费用

任务声明 CPU 并行度、内存、临时磁盘、GPU 纹理、截止时间和可选外部费用预算。宿主在派发前预留资源，并为整个子进程树统计使用。Windows 使用 Job Object 管理自有任务树；Linux/macOS 使用对应进程组和可用资源限制，无法强制的指标明确作为观测值。

纯计算超时或预算用尽产生失败及诊断；工程当前修订保持。外部请求发送后超时按实际效果核对，费用预留保留至结算或确认无消费。提高预算需要明确调整配置，重启任务不清零历史消费。

导出峰值包含源工程、解码像素、图集、序列化、目标编译进程和临时文件；按阶段释放资源。资源不足时给出所需数量和可调整项，不通过减少关键形、删除姿态或改变纹理精度偷偷满足预算。

## 5. 依赖与发行攻击面

依赖版本和安装脚本锁定，构建下载校验来源与摘要。外部贡献 CI 无发布凭据、目标软件令牌和用户工程访问。原生兼容测试只在受控运行器使用合成工程。

构建清单使用显式允许集合；扫描秘密、用户路径、开发控制文件、未登记资产和许可证通知。供应链检查发现具体问题时定位实际组件和版本，修复或替换后检查受影响产物。
